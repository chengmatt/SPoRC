# Compute Biomass

Compute Biomass

## Usage

``` r
compute_biom_y(
  y,
  seas,
  NAA,
  NAA0,
  WAA,
  MatAA,
  ZAA,
  natmort,
  t_spawn,
  seasdur,
  n_seas,
  n_pop,
  n_regions,
  n_ages,
  n_sexes,
  sgl_seas_spawning_movement,
  natal_region,
  stray_rate
)
```

## Arguments

- y:

  Year integer

- seas:

  Season integer
