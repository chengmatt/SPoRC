# Two-category Dirichlet-multinomial (beta-binomial) log-density

Two-category Dirichlet-multinomial (beta-binomial) log-density

## Usage

``` r
ddirmult2(obs2, alpha2)
```

## Arguments

- obs2:

  Length-2 count vector `c(count_a, count_remaining)`.

- alpha2:

  Length-2 concentration `c(alpha_a, alpha_remaining)`.

## Value

Scalar log-density.
