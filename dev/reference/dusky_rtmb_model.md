# Dusky model outputs from single regino model

A list containing inputs and outputs for the 2024 GOA Dusky Rockfish
Assessment

## Usage

``` r
dusky_rtmb_model
```

## Format

Data list for single region dusky rockfish assessment

## Source

Omori, K. L., Williams, B. C., Hulson, P.-J., Ferriss, B. 2024.
Assessment of the dusky rockfish stock in the Gulf of Alaska. North
Pacific Fishery Management Council, Anchorage, AK.
