# Flatten a reference point array into a named vector

Flatten a reference point array into a named vector

## Usage

``` r
flatten_refpt(x, prefix)
```

## Arguments

- x:

  Numeric vector or array of reference point values.

- prefix:

  Character. Name stem, e.g. `"f_ref_pt"`.

## Value

Named numeric vector. Length one input keeps the bare prefix.
