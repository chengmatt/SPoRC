# Number of length bins the observed compositions are recorded on

The model's own bins unless a length bin map was given, in which case
the observed compositions sit on the map's columns.

## Usage

``` r
obs_len_bins(input_list)
```

## Arguments

- input_list:

  Input list after
  [`Setup_Mod_Biologicals`](https://chengmatt.github.io/SPoRC/dev/reference/Setup_Mod_Biologicals.md).
