# Deviation arrays a dsem may set from its arrows alone

A dsem series with an sd of zero is a function of its covariates rather
than a deviation with a density, so something has to write it into the
model. The density sits just before the observation models, so
catchability is still ahead of it; growth, movement, recruitment and the
numbers at age are all consumed before it, so a zero sd on one of those
is refused. This is the one list, read by that refusal and by the
objective.

## Usage

``` r
q_dev_par_names()
```

## Value

Character vector of parameter array names.
