# Validate the raw double normal limb flags

Validate the raw double normal limb flags

## Usage

``` r
setup_dbnrml_raw(x, n_fleets, what)
```

## Arguments

- x:

  `NULL` or a 0/1 matrix `[n_fleets x 2]`.

- n_fleets:

  Number of fleets.

- what:

  Argument name for messages.

## Value

An integer matrix `[n_fleets x 2]`, all zero for `NULL`.
