# BSAI northern rock sole data for single region assessment case study

A data list containing inputs for the 2024 BSAI Northern Rock Sole
Assessment (flatfish model, Model 24.2), together with the assessment's
maximum likelihood estimate and its reported output. The model is two
sex with sex specific natural mortality, free initial numbers at age
estimated separately for each sex, time varying logistic fishery
selectivity with a male curve offset, and a survey read as a July
biomass index against January 1 compositions.

## Usage

``` r
sgl_rg_bsai_nrs_data
```

## Format

Data list for single region northern rock sole assessment

## Source

McGilliard, C. R., Palsson, W., Haehn, R. 2024. Assessment of the
northern rock sole stock in the Bering Sea and Aleutian Islands. North
Pacific Fishery Management Council, Anchorage, AK.
