# BSAI Pacific Ocean Perch data for single region case study

A dataset containing the necessary elements for the BSAI Pacific ocean
perch case study, including model inputs (dimensions, biologicals,
catch, two survey indices, and compositions), the ADMB MLE parameter
estimates, and the ADMB derived quantities and likelihood components
used for bridge verification.

## Usage

``` r
sgl_rg_bsai_pop_data
```

## Format

A list with model inputs at the top level, `mle` (ADMB maximum
likelihood estimates), and `admb` (ADMB derived quantities and
likelihood components for bridge comparison)

## Source

2024 Federal BSAI Pacific Ocean Perch Assessment
