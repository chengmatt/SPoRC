# EBS walleye pollock data for the Rceattle case study

Inputs for the September 2026 version of the eastern Bering Sea walleye
pollock base model (Model 26.0), 1964 to 2024 at ages 1 to 15 with a
plus group: catch, age compositions and an early CPUE from one fishery,
the bottom trawl and acoustic trawl survey indices and age compositions,
the acoustic vessels of opportunity index and the acoustic age 1 index
(`inputs`), with the estimates `Rceattle` returns for the same inputs
(`rceattle`), used to start and check the bridge.

## Usage

``` r
sgl_rg_ebswp_m26_data
```

## Format

Data list containing inputs and outputs for the 2026 EBS Pollock
Assessment

## Source

Ianelli, J., Wassermann, S., McCarthy, A., McGilliard, C., Siddon, E.,
Shotwell, K., Adams, G., Lauffenburger, N. 2026. 2026 Assessment of
Eastern Bering Sea Walleye Pollock. North Pacific Fishery Management
Council.
