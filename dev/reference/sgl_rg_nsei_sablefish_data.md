# Northern Southeast Inside sablefish data for the TMB case study

Inputs for the 2025 Northern Southeast Inside (NSEI) sablefish
assessment of the Alaska Department of Fish and Game, a sex-structured
statistical catch-at-age model written in TMB, 1975 to 2025 at ages 2 to
31 with a plus group: landed catch, age and length compositions from one
fishery, a longline survey index with age and length compositions, a
fishery CPUE index and a mark-recapture abundance index, with the
estimates the TMB model returns for the same inputs, used to check the
bridge.

## Usage

``` r
sgl_rg_nsei_sablefish_data
```

## Format

Data list containing inputs and outputs for the 2025 NSEI sablefish
Assessment

## Source

Lambert, A. W., Ehresmann, R. K. 2026. 2026 Northern Southeast Inside
Subdistrict sablefish management plan and stock assessment. Alaska
Department of Fish and Game, Division of Commercial Fisheries, July
2026. Model code `scaa_mod_v23_Aaron2.cpp`, run
`v23_3f_3s_2016_NEW_FINAL`, at
<https://github.com/commfish/seak_sablefish>.
