# One replicate's parameter list for the fleet deviations

One replicate's parameter list for the fleet deviations

## Usage

``` r
sim_fleet_dev_pars(sim_env, sim)
```

## Arguments

- sim_env:

  Simulation environment.

- sim:

  Replicate.

## Value

The replicate's own under a joint self test, else the one every
replicate shares.
