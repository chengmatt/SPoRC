# One replicate's growth deviations without the replicate dim

One replicate's growth deviations without the replicate dim

## Usage

``` r
sim_growth_devs(sim_env, par_name, sim)
```

## Arguments

- sim_env:

  Simulation environment.

- par_name:

  `"ln_growth_devs"` or `"ln_growth_semipar_devs"`.

- sim:

  Replicate.

## Value

The five-dim array `Get_Growth` takes, or `NULL` when the operating
model holds no such array.
