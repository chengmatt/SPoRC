# ggplot2 theme for SPoRC plots

A clean `theme_bw`-based ggplot2 theme with enlarged text elements
suitable for publication-quality SPoRC diagnostic and results figures.

## Usage

``` r
theme_sablefish()
```

## Value

A `ggplot2` theme object.
