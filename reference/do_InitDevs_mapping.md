# Helper function to handle mapping for ln_InitDevs

Helper function to handle mapping for ln_InitDevs

## Usage

``` r
do_InitDevs_mapping(input_list, InitDevs_spec, rec_dd)
```

## Arguments

- input_list:

  Input list

- InitDevs_spec:

  Character vector for specifying InitDevs mapping

- rec_dd:

  Recruitment density dependence indicator (global vs. local)
