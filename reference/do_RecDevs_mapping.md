# Helper function to handle RecDevs mapping

Helper function to handle RecDevs mapping

## Usage

``` r
do_RecDevs_mapping(input_list, RecDevs_spec, rec_dd)
```

## Arguments

- input_list:

  Input list

- RecDevs_spec:

  Character vector for specifying RecDevs mapping

- rec_dd:

  Recruitment density dependence indicator (global vs. local)
