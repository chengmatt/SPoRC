# Helper function to set up fishery process error mapping

Helper function to set up fishery process error mapping

## Usage

``` r
do_fishsel_pe_pars_mapping(input_list, fishsel_pe_pars_spec, corr_opt_semipar)
```

## Arguments

- input_list:

  Input list

- fishsel_pe_pars_spec:

  Character vector specifying fishery process error parameterization

- corr_opt_semipar:

  Character vector specifying correlation parameter options
