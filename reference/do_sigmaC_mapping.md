# Helper function to setup sigma C and sigma C agg mapping

Helper function to setup sigma C and sigma C agg mapping

## Usage

``` r
do_sigmaC_mapping(input_list, sigmaC_spec, sigmaC_agg_spec)
```

## Arguments

- input_list:

  Input list

- sigmaC_spec:

  Character vector for sigmaC specification

- sigmaC_agg_spec:

  Character vector for sigmaC_agg specification
