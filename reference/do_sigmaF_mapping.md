# Helper function to setup sigma F and sigma F agg mapping

Helper function to setup sigma F and sigma F agg mapping

## Usage

``` r
do_sigmaF_mapping(input_list, sigmaF_spec, sigmaF_agg_spec)
```

## Arguments

- input_list:

  Input list

- sigmaF_spec:

  Character vector for sigmaF specification

- sigmaF_agg_spec:

  Character vector for sigmaF_agg specification
