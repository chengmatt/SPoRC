# Helper function to set up survey process error mapping

Helper function to set up survey process error mapping

## Usage

``` r
do_srvsel_pe_pars_mapping(input_list, srvsel_pe_pars_spec, corr_opt_semipar)
```

## Arguments

- input_list:

  Input list

- srvsel_pe_pars_spec:

  Character vector specifying survey process error parameterization

- corr_opt_semipar:

  Character vector specifying correlation parameter options
