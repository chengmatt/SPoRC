# Get scaled parameters for a scaled beta distribution

From
https://stackoverflow.com/questions/75165770/beta-distribution-with-bounds-at-0-1-0-5

## Usage

``` r
get_beta_scaled_pars(low, high, mu, sigma)
```

## Arguments

- low:

  lower bound

- high:

  upper bound

- mu:

  mean in normal space

- sigma:

  sigma in normal space

## Value

Returns beta distribution parmeters with bounds
