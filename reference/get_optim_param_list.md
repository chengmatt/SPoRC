# Title Populates an unoptimized parameter list with optimized values

Title Populates an unoptimized parameter list with optimized values

## Usage

``` r
get_optim_param_list(parameters, mapping, sd_rep, random)
```

## Arguments

- parameters:

  Parameter list

- mapping:

  Mapping list

- sd_rep:

  Sd report list from RTMB

- random:

  Character vector of whether random effects were estimated

## Value

Updated parameter list with associated optimized parameters
corresponding to the same mapping indices
