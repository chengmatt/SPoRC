# Sablefish report for 3 region case study

A report containing results for the spatial Alaska sablefish case study.

## Usage

``` r
three_rg_sable_rep
```

## Format

Report file from the 3 region sablefish case study

## Source

Cheng et al. 2025, Fish and Fisheries; Panmictic Panacea? Demonstrating
Good Practices for Developing Spatial Stock Assessments through
Application to Alaska Sablefish (Anoplopoma fimbria)
